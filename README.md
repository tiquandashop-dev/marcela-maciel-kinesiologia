# Sitio de Lic. Marcela Maciel

Proyecto independiente de Next.js para desplegar como sitio separado.

## Desarrollo local

```powershell
npm install
npm run dev
```

Abrir `http://localhost:3000` (o el puerto que Next indique).

## Personalización

- `data.js`: textos, servicios, reseñas, teléfono, WhatsApp y foto.
- `app/page.js`: estructura visual y diseño.
- `app/globals.css`: tipografías y estilos globales.

En Vercel, usar esta carpeta como **Root Directory** para desplegar solo este sitio.
